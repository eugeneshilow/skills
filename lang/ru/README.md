# skills

Скиллы для ИИ-агентов от [Евгения Шилова](https://github.com/eugeneshilow): готовые умения, которые агент для кода берёт, когда они нужны. Каждый скилл лежит в своей папке с файлом `SKILL.md` в формате [Agent Skills](https://agentskills.io), поэтому он работает в Claude Code, Codex, Cursor и любом другом агенте, который читает скиллы.

Это русская версия. Источник лежит в корне репозитория на английском, этот файл повторяет его. Сами скиллы написаны по-английски: агент читает их на любом языке и отвечает вам на вашем.

Скиллы выросли внутри живой компании, которая работает по [Spec-Driven Company](https://github.com/eugeneshilow/spec-driven-company): метод даёт правила, которые каждый агент читает первыми, а скиллы добавляют поверх них ремёсла. Каждым пользуемся каждый день, прежде чем выложить.

## Скиллы

| Скилл | Что делает | Скажите агенту |
| --- | --- | --- |
| [research-pass](../../skills/research-pass/) | Исследование, которое не теряется: на каждый заход своя папка с датой, итог и сырой вывод агентов, у каждого факта адрес источника и дата, обязательный раздел «Не найдено», и второй агент, который пытается опровергнуть главные цифры. | «Исследуй X и сохрани как research-pass» |
| [deslop-ru](../../skills/deslop-ru/) | Убирает следы машинного письма из русского текста в два прохода: сначала сканер слов по словарю, потом проверка риторики свежим взглядом по списку из десяти пунктов. Правки приходят таблицей «было → стало». | «Де-слоп этот текст» |
| [second-opinion](../../skills/second-opinion/) | Независимое ревью другой моделью, только там, где риск: деньги, вход и доступы, схема данных, деплой, публичная методика. Внутри шаблон брифа и команды запуска только на чтение. | «Дай второе мнение по этому» |
| [prodamus-payments](../../skills/prodamus-payments/) | Приём оплаты картой через Продамус (payform.ru): подписанная ссылка на оплату, вебхук, который проверяет заголовок `Sign` и записывает каждый платёж один раз, проверка в демо-режиме. Код подписи на TypeScript и Python, сверен с примерами из официального `Hmac.php`. | «Подключи оплату через Продамус» |

## Установка: вставьте в агента

Откройте своего агента для кода (Claude Code, Codex, Cursor, любой другой) и вставьте промпт. Не в терминал, а в агента. В конце агент отчитается: где теперь лежит скилл и какой фразой его звать.

**Один скилл.** В примере ставится `deslop-ru`; для другого скилла впишите его имя из таблицы во все места.

```text
Поставь мне скилл https://github.com/eugeneshilow/skills/tree/main/skills/deslop-ru. Склонируй https://github.com/eugeneshilow/skills командой git clone --depth 1 во временную папку и скопируй из неё папку skills/deslop-ru в ~/.claude/skills/deslop-ru/, чтобы скилл работал во всех проектах; если ты Codex, копируй в ~/.codex/skills/deslop-ru/. Если такая папка уже есть, замени её: так скилл обновляется. Файлы не правь. Временную папку удали. Готово, когда есть ~/.claude/skills/deslop-ru/SKILL.md (или путь Codex) и в его строке name написано deslop-ru. Отчитайся: путь и фраза, которой звать скилл.
```

**Все скиллы.**

```text
Поставь мне все скиллы из https://github.com/eugeneshilow/skills. Склонируй репозиторий командой git clone --depth 1 во временную папку и скопируй каждую папку из его skills/ в ~/.claude/skills/, чтобы скиллы работали во всех проектах; если ты Codex, копируй в ~/.codex/skills/. Если папка с таким именем уже есть, замени её: так скиллы обновляются. Файлы не правь. Временную папку удали. Готово, когда в каждой скопированной папке лежит SKILL.md. Отчитайся: список поставленных скиллов и фраза, которой звать каждый.
```

Если скилл не появился, начните в агенте новую сессию.

## Установка: команды

То же самое руками. Один скилл или все сразу, в Claude Code:

```bash
npx skills add eugeneshilow/skills                       # выбрать из списка
npx skills add eugeneshilow/skills --skill research-pass # один скилл
```

Как плагин Claude Code:

```text
/plugin marketplace add eugeneshilow/skills
/plugin install shilov-skills@shilov-skills
```

Руками: скопируйте папку из `skills/` в `~/.claude/skills/` (для всех проектов) или в `.claude/skills/` (для одного проекта). Codex читает те же папки из `~/.codex/skills/`; у каждого скилла есть `agents/openai.yaml` для списка скиллов в Codex.

Два скилла зовут третий, если он стоит, и работают без него:

- `research-pass` отдаёт проверку главных цифр на опровержение скиллу `second-opinion`.
- `prodamus-payments` перед запуском в бой отправляет модуль подписи и вебхук в `second-opinion`.

## Устройство

```text
skills/<name>/SKILL.md      сам скилл: name и description в шапке, инструкции в теле
skills/<name>/references/   подробности, которые агент читает только когда нужно
skills/<name>/scripts/      помощники, которые запускает скилл
skills/<name>/agents/       openai.yaml: имя, одна строка и промпт по умолчанию для списка скиллов в Codex
template/SKILL.md           заготовка для нового скилла
scripts/validate-skills.mjs проверка, которую CI гоняет на каждом изменении
lang/ru/README.md           этот файл
```

Язык: репозиторий на английском, этот файл повторяет README по-русски. Скилл, который работает с русским текстом, держит русские примеры и списки слов как данные; инструкции остаются на английском.

## Сделайте их своими

Эти скиллы можно и нужно править под себя. Личные настройки держите в своём `CLAUDE.md` или `AGENTS.md`: тогда скиллы можно обновить и ничего не потерять: например, какая модель даёт второе мнение и где в репозитории лежат исследования. Агент читает правила проекта раньше любого скилла, поэтому побеждают они.
